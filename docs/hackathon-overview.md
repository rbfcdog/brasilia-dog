# NextWave Hackathon 2026 overview

_Event rules and schedule for a four-person Yuno × Nauta hackathon crew._

---

## Event model

Yuno × Nauta presents NextWave Hackathon 2026. OpenAI, Tecnológico de Monterrey, Universidad Torcuato Di Tella, Pontificia Universidad Javeriana in Bogotá, and ECBR in E-commerce Brasil support the event.

A crew of four has one weekend to choose one challenge and ship a working prototype. The event favors a narrow system that works from start to finish and survives live operation over a broad demo with missing pieces.

## Universal protocol

| Rule | Requirement |
| --- | --- |
| Select one track | Each crew tackles one of the four challenges. The selection is final |
| Invent freely | Teams may invent data, flows, APIs, databases, and protocols. Any technical choice must be defensible |
| Pass trial by fire | Judges operate the system live with unrehearsed changes or input. The system must react without team intervention |

## Timeline and judging format

| Moment | Detail |
| --- | --- |
| Code freeze | Submission material locks at code freeze |
| Sunday, August 30 | Pitches begin after code freeze. City champions and global winners are announced the same day, following each site’s local hours |
| Standard presentation | Short pitch, live demo, trial by fire, then technical Q&A |
| Standard team slot | 10 minutes per team |
| City champion final | 15 minutes: 10 minutes for the presentation and 5 minutes for questions |
| Judges | Yuno and Nauta. The full panel sees every project, ranks independently, then deliberates |
